# Historical submission artifacts

The PDF, video, result copies, and replay files in this directory record the original nine-run experiment with the start-aligned map. They remain unchanged so their recorded checksums and the later comparison's provenance remain verifiable.

The completed aligned-memory follow-up is documented in [the current full comparison](../results/memory-alignment-comparison/report.md) and [architecture rationale](../docs/architecture-rationale.md). Its selected models are in [checkpoints/aligned](../checkpoints/aligned). The historical report/demo and local Windows build have not yet been refreshed to present that follow-up as the final submission.

## License erratum

The historical PDF's reference line incorrectly labels MiniGrid as MIT. The retained upstream [LICENSE](../LICENSE) is **Apache 2.0**. This correction is reflected in current project metadata, [ATTRIBUTION.md](../ATTRIBUTION.md), README, and the report generator. The original license file and upstream [CITATION.cff](../CITATION.cff) have not been changed.
